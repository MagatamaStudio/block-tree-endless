# 自动化商店

## 入口

科技树右侧的 **「商店」** 节点打开自动化商店。

商店对应全部 **36 层**，每层一件商品；原版六层与 30 个模组层都可以自动化。

## 规则

- **本层首通后**才能购买本层自动化，价格用**本层资源**支付。
- 价格 = 本层声望需求的 **2 倍**（需求已含全局难度）。
- 购买后同时解锁自动购买与自动声望，默认开启；每张卡片内有**自动购买**与**自动声望**两个开关，可分别切换。
- 自动购买覆盖普通升级与购买项（4 座设施、主题核心），不会自动分配科技层的研究点。
- 自动购买会为**下一层声望保留所需资源**：只有超过下一层需求的部分才会花掉，不会把声望卡死。
- 自动声望：本层前置资源（上一层资源）达到 **1.5 倍需求**时自动完成一次声望；转生「记忆捷径」每级让这次声望的收益 ×1.10（最高 ×2.0），阈值固定 1.5 倍。商店顶部的「自动声望总开关」是全局开关，关闭后已购自动化只买不转。
- 自动声望不会回退到**上次声望的下限**以下：高层声望保留的低层不会被自动声望逐 tick 连锁重置；想重置更低层，手动点该层声望即可。第一层「橡木林」豁免下限，永远可以自动声望。商店顶部会显示当前回退下限与被下限暂停的层数，对应层卡片也会标注「暂停·低于回退下限」。
- 每个 tick 最多自动声望一次，避免同一帧级联多次重置。
- 挑战进行中该层的自动购买会暂停；自动声望在任意挑战进行中都暂停，避免花掉挑战进度或提前退出挑战。
- **启动套件**：已首通且重置前拥有 12 号升级的层被回退时，会保留 12 号升级与 1 级生产设施，自动产出不需要每次重置后手动重启。
- v6.5 及更早版本用「下一层资源购买上一层自动化」解锁的记录全部保留，价格按新规则计算。

## 例子

| 商品 | 支付货币 | 效果 |
| --- | --- | --- |
| 橡木林 | 木板 | 首通橡木林后解锁；自动购买与自动声望 |
| 末地 | 末影珍珠 | 首通末地后解锁；自动购买与自动声望 |
| 暮色森林 | 娜迦鳞片 | 首通暮色森林后解锁；自动购买与自动声望 |
| 无尽贪婪 | 无尽催化剂 | 首通无尽贪婪后解锁；自动购买与自动声望 |

## 注意

- 自动购买不会自动分配研究点；科技层的 15–17 号研究分支仍需手动点。
- 自动购买不会代投入材料；自动声望会等本轮施工完成才触发（手动可以提前声望，但收益按施工进度折算）。真转生会把模组层的首通与施工一起清零，下一轮要重新施工；记忆里的永久升级不受影响。
- 自动化购买本身不受「保留下一层资源」限制，可以随时手动购买。

## 实现

- 商店层与商品：`js/layers/shop.js`
- 自动购买执行：`js/game.js` 中的 `autobuyUpgrades` 与 `autobuyBuyables`
- 自动声望：`js/game.js` 中的 `shopAutoPrestigeReady`，阈值经 `autoPrestigeMult()` 读取，默认 `AUTO_PRESTIGE_MULT = 1.5`，记忆捷径按等级放大这次声望的收益
- 回退下限：`player.resetFloor` 记录上次声望的回退下限，`autoResetFloor` 用它阻止自动声望继续下探；`row 0` 直接返回 0，所以第一层永远不受下限限制
- 声望保留额：`shopAutoReserve` 读取下一层的 `requires`；挑战中由 `isInChallenge` 跳过代买
- 启动套件：`js/game.js` 中的 `retainStartKit`
- 已购标记：`player.shop.owns`
- 自动购买开关：`player.shop.autoBuy`
- 本层自动声望开关：`player.shop.autoPrestigeLayer`
- 自动声望总开关：`player.shop.autoPrestige`
- 旧档迁移：`player.shop.auto` 在 `player.shop.autoMigrated` 为 false 时一次性回填到上述两个单层开关
