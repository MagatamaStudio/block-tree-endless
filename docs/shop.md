# 自动化商店

## 入口

科技树右侧的 **「商店」** 节点打开自动化商店。

商店共有 **35 件商品**，对应原版与模组层中的前 35 层。最后一级「创造模式」没有下一层，因此没有对应的上一层自动购买。

## 规则

- 商品购买的是**上一层**的自动购买权。
- 价格使用**下一层**的资源支付。
- 价格 = 下一层声望需求的 **8 倍**。这个需求数值本来以「再下一层」的资源计，但商店会把它换算成下一层的资源来显示和扣费。例如进入石矿洞需要 150 木板，则「自动·橡木林」标价 8 × 150 = 1200 圆石，属于长期投资。
- 购买后解锁一个自动购买开关，默认开启；再次点击商品卡片即可开启/关闭。
- 自动购买开关保存在 `player.shop.auto`，不会因为上一层被声望重置而丢失。
- 每件商品只能购买一次；购买后点击只切换开关，不再扣资源。

## 例子

| 商品 | 支付货币 | 效果 |
| --- | --- | --- |
| 自动·橡木林 | 圆石 | 解锁橡木林自动升级开关（可开关） |
| 自动·末地 | 娜迦鳞片 | 解锁末地自动升级开关（可开关） |
| 自动·暮色森林 | 魔力钢 | 解锁暮色森林自动升级开关（可开关） |
| 自动·无尽贪婪 | 创造能量 | 解锁无尽贪婪自动升级开关（可开关） |

## 注意

- 自动购买会持续消耗上一层的资源，可能让上一层更难攒够下一次声望；这是商店的代价。
- 自动购买只处理**升级**，不会自动购买 4 座自动化设施，也不会自动声望。
- 硬上限会限制下一层资源，因此价格虽然高，但不会超过对应货币的硬上限。

## 实现

- 商店层与商品：`js/layers/shop.js`
- 自动购买执行：`js/game.js` 中的 `autobuyUpgrades`
- 已购标记：`player.shop.owns`
- 开关状态：`player.shop.auto`
- 商店入口：科技树侧边层 `shop`
