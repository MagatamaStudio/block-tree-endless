# 彩蛋控制台

> 剧透警告：本文包含隐藏入口口令。

## 打开方式

1. 点击左上角齿轮进入设置页。
2. 找到最下方的 **「系统诊断」** 按钮。
3. 在弹出框中输入：

```text
我永远喜欢庄方宜
```

口令正确后会打开本地控制台。控制台只修改当前浏览器里的存档，不会连接服务器。

## 指令

| 指令 | 作用 |
| --- | --- |
| `help` / `?` | 查看指令列表 |
| `give <层> <数量>` | 给指定层增加资源，例如 `give p 1000` |
| `log <数量>` | 增加原木 |
| `rp <层> <数量>` | 给科技层增加研究点，例如 `rp ae 50` |
| `time <小时>` | 推进游戏时间，例如 `time 12`（不推进施工） |
| `skip <层>` | 直接补满该层本轮施工，不消耗材料（v8.6 起已无施工券） |
| `unlock <层>` | 解锁指定层 |
| `unlockall` | 解锁全部层 |
| `auto <层>` | 直接解锁该层自动化 |
| `deep [层] [数量]` | 无参数查看深层反哺倍率；带层与数量时把该层 `everBest` 提到指定值 |
| `reset <层>` | 执行一次该层声望 |
| `god` | 给所有层注入资源 |
| `cap <层>` | 查看软上限 |
| `build <层>` | 查看该层施工进度（`wall` 仍可用） |
| `best <层>` | 查看该层资源、`best`、`everBest` 与研究点 |
| `ls [前缀]` | 列出层及解锁、首通状态 |
| `stat` | 查看版本、层数、成就、产量、存档大小等全局状态 |
| `save` | 立即保存 |
| `clear` | 清空控制台输出 |
| `reload` | 重新加载页面 |
| `close` | 关闭控制台 |

## 交互

- `↑` / `↓`：翻看本次打开期间的历史指令。
- `Tab`：补全指令名；输入指令后再按一次可补全层 id。
- `Ctrl+L`：清屏。
- 点击任意一条历史指令，会把它重新填回输入框。

## 示例

```text
give t 1000
time 24
unlock b
cap t
```

`give`、`log`、`rp` 与 `deep` 支持 Decimal 字符串，例如 `give cr 1e12`。

## 实现说明

- 界面入口在 `js/technical/systemComponents.js` 的设置页模板。
- 控制台逻辑在 `js/easter-egg.js`。
- 口令通过 Unicode 转义拆分，控制台函数与变量使用短命名，相关文件不写注释。
- 控制台样式在 `css/minecraft.css` 的 `.eggbox` 段。
- 作弊会直接修改 `player`，建议先用 `save` 保存，或使用浏览器控制台/本地存档备份后再试。

## 注意

这是一个单机彩蛋，不是安全功能。口令只是隐藏入口，不能保护存档；任何能打开浏览器开发者工具的人都可以直接修改 `player`。
